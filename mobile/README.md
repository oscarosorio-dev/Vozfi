# 

## Instalar nuevas librerías
```bash
npx expo install nombre-del-paquete
```

## Flujo de comandos comunes con Yarn
1. Iniciar el servidor de desarrollo:
```bash
yarn start
```

2. Instalar paquetes puramente de JavaScript (como librerías de utilidad):
```bash
yarn add nombre-de-la-libreria
```

3. Instalar una dependencia de desarrollo (como linters o TypeScript):
```bash
yarn add -D nombre-de-la-libreria
```
